## 🔧 IMAGE OPTIMIZATION TOOLS

### Before Upload:
1. **TinyPNG** (tinypng.com) - Compress images
2. **Squoosh** (squoosh.app) - Google's image optimizer
3. **ImageOptim** (imageoptim.com) - Mac app
4. **RIOT** - Windows optimizer

### Batch Processing:
```bash
# Using ImageMagick (install first)
# Resize all images to 800x600
mogrify -resize 800x600 -quality 85 *.jpg

# Convert to WebP
for i in *.jpg; do cwebp -q 85 "$i" -o "${i%.jpg}.webp"; done
```
